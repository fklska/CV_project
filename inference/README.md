# Inference viewer

HTML-страница со слайдером для просмотра восстановленных кубов: как куб заполняется по оси, в которой были пропуски.

## Запуск

```
.venv\Scripts\python.exe inference\serve.py --port 8000
```

Затем открыть в браузере `http://127.0.0.1:8000` — страница доступна только через сервер (прямое открытие `index.html` не работает, запросы идут к серверу).

Нужен Python с numpy (венв проекта `.venv`); других зависимостей нет.

## Как это устроено

- Сервер автосканит `output/<sub>/{inpainting,outpainting}_cube_restored.npy`. Новый куб (например, после прогона outpainting) появится в списке после обновления страницы, перезапуск сервера не нужен.
- Исходные кубы `input_seismic_data/{inpainting,outpainting}_cube_missed_data.npy` всегда показаны в селекторе с меткой «исходный»: в них область пропусков обнулена — удобно сравнить с результатом. Ноль — ниже p1 известной части куба, поэтому в исходных кубах пропуск квантуется в чёрный и сливается с фоном; чтобы пропуск был очевиден, в исходных кубах область пропусков дополнительно закрашивается полупрозрачной подложкой + штриховкой с подписью «нет данных».
- В RAM держится один куб (~1 ГБ): при переключении на другой предыдущий высвобождается и новый грузится заново (~1–3 с, в терминале сервера печатается время загрузки).
- Области пропусков заданы жёстко в `serve.py` (`TASKS`):
  - inpainting — `[:, 368:581, 179:282]`, ось слайдера по умолчанию 0;
  - outpainting — `[:, 0:24, :]` и `[:, 457:481, :]`, ось слайдера по умолчанию 1.
- Одна панель — результат: полный срез (отображается крупно), область пропусков обведена красным; в исходных кубах поверх пропусков — штриховка + подпись «нет данных» (см. выше), в восстановленных — только красный контур; по краям — подписи размерностей осей (ось K · M).
- При смене оси или куба слайдер сбрасывается не в 0, а в позицию, где область пропусков видна (если 0 внутри области — остаётся 0, иначе — середина первого интервала пропусков по этой оси; например, у исходного inpainting-куба ось 1 стартует с 474 — центр полосы 368–580).
- Масштаб серости: p1–p99 по всем известным значениям куба (одна шкала на все срезы).

## Аргументы

| аргумент | по умолчанию | значение |
|---|---|---|
| `--host` | `127.0.0.1` | адрес привязки |
| `--port` | `8000` | порт |
